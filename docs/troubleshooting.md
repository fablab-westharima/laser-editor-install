# 困ったとき

うまくいかないときの見分け方です。**まず「何が起きているか」を切り分けてから**手を動かしてください。

> **繰り返し入れ直すのは、たいてい状況を悪くします。**
> 特に Docker Desktop は、途中で止まった状態が残ると「すでに入っている」と誤認されて
> 復旧が難しくなります。同じ操作を 2 回試して駄目なら、画面をそのままにしてご相談ください。

---

## インストーラが途中で止まった

インストーラは**止まった理由によって終わり方を分けています**。

| 画面に出るもの | 意味 | どうするか |
|---|---|---|
| **`[laser-editor 準備が必要]`** | Docker 側の準備がまだ | 書かれているとおり Docker を整えてから**もう一度実行**。**LaserEditor は何も変更していません** |
| **`[laser-editor ERROR]`** | LaserEditor 自身のインストールに失敗 | 画面の内容をそのままご連絡ください |

コマンドで確認する場合の終了コードは、**3 = 準備が必要**、**1 = インストール失敗** です。

**「準備が必要」で止まった場合、その機械には何も入っていません。** 消したり戻したりする必要はありません。

---

## Docker Desktop が見つからないと言われる（Mac / Windows）

LaserEditor は Docker Desktop を入れません。ご自身でインストールしてください。

1. https://www.docker.com/products/docker-desktop/ から公式インストーラを入手
2. Docker Desktop を**起動**する
3. **初回セットアップを最後まで進める**
4. クジラのアイコンが動きを止めて安定する（**Engine running**）まで待つ
5. LaserEditor のインストーラをもう一度実行

---

## Docker Desktop は入っているのに「まだ使える状態ではない」と言われる

**初回セットアップが終わっていません。** よくあるのは、インストール直後に画面を閉じてしまった場合です。

Docker Desktop を開いて、案内（**Use recommended settings → Finish**）を最後まで進めてください。
途中で管理者パスワードを求められたら入力します。**Engine running** になったら、
LaserEditor のインストーラをもう一度実行してください。

**入れ直す必要はありません。入れ直しても直りません。**

---

## Docker が「起動しない」（Windows）

原因の大半は **CPU の仮想化が無効**であることです。

1. **Ctrl + Shift + Esc** → **パフォーマンス → CPU**
2. 右下の **「仮想化」** を見る

**「無効」なら、これは PC 本体の BIOS / UEFI の設定で、Docker を入れ直しても直りません。**
[Windows の手順書](setup-windows.md#0-はじめる前の確認1-分何も変更しません) の選択肢を見てください。

---

## LaserEditor の画面が開かない

1. **Docker が動いているか** — クジラのアイコンが「Engine running」になっているか
2. **アドレスが合っているか** — 同じ機械からなら `http://localhost:8000`、
   別の機械からなら `http://<その機械のIP>:8000`
3. それでも駄目なら、**インストーラをもう一度実行**してください（修復を兼ねています）

---

## PC を再起動したら上がってこない

**Docker Desktop がサインイン時に起動する設定になっていない**ことがほとんどです。

Docker Desktop の **設定 → General → 「Start Docker Desktop when you sign in」** を ON にしてください。

Raspberry Pi / Linux では自動で復帰します。

---

## 管理画面にログインできない

管理トークンはインストール先の **`管理トークン.txt`** にあります
（Raspberry Pi は `/opt/laser-editor/.env` の `LASER_ADMIN_TOKEN`）。

画面右上の **[トークン再設定]** を押すと、ファイル選択からやり直せます。

---

## スキャンしても共有棚に出てこない

まず、**その構成で自動取込が使えるか**を確認してください。

| 構成 | 自動取込 |
|---|---|
| ScanSnap と LaserEditor が**同じ Mac / Windows** | 使えます |
| LaserEditor が**Raspberry Pi など別の機械** | **使えません。** 管理画面へドラッグ＆ドロップしてください |

同じ機械の場合の確認:

1. `.env` に `LASER_EXTERNAL_INBOX_HOST` を書いたか
2. そのパスが**実際のフォルダ**を指しているか
3. **Windows は区切りが `/`** になっているか（`\` だと何も起きません）
4. 書いたあとに**インストーラをもう一度実行**したか

管理画面の**取込タブ**に、監視しているフォルダの状態が出ます。

---

## 同じ絵を 2 回取り込んでしまった

**二重にはなりません。** 内容そのもので判定しているので、同じ画像は 1 つとして扱われます
（ファイル名を変えても同じです）。

---

## アンインストールしたのにフォルダが残っている

**それが正しい動作です。** 通常のアンインストールでは、参加者のデザインと設定を残します。

完全に消す方法は [運用ガイド](operations.md#データごと完全に消す) を見てください。

---

## LightBurn が見つからない / 加工キューが動かない

**LaserEditor は LightBurn を入れません。** LightBurn は別途ご用意ください。
連携の仕組みは [LightBurn 連携](lightburn.md) を見てください。

LightBurn を使わない運用もできます。管理画面から **PNG をダウンロード**して、
お使いの加工ソフトで開いてください。

---

## それでも解決しないとき

次の情報を添えてご連絡ください。

- どの機械か（Mac / Windows / Raspberry Pi）
- 画面に出ている文字（`[laser-editor 準備が必要]` なのか `[laser-editor ERROR]` なのか）
- どの手順で止まったか

**直そうとして設定をいろいろ変える前にご連絡いただくほうが、結果的に早く済みます。**
