# 困ったとき

## インストーラーが途中で止まった

画面の見出しを確認します。

| 表示 | 意味 | 次にすること |
|---|---|---|
| **準備が必要** | Docker Desktop側の準備が途中 | 画面の案内を済ませ、同じインストーラーを再実行 |
| **ERROR** | LaserEditorの導入に失敗 | 画面の内容をそのまま連絡 |

内部の終了コードは、準備不足が **3**、LaserEditor本体の失敗が **1** です。

## Docker Desktopが見つからない

LaserEditorはDocker Desktopを入れません。
[公式サイト](https://www.docker.com/products/docker-desktop/)から導入し、起動して初回設定を
最後まで進め、**Engine running**になってからインストーラーをもう一度実行します。

## ダブルクリックしても必要なファイルが無いと言われる

ZIPを開いた画面から直接実行せず、ZIP全体を展開してから、展開先の
`LaserEditor をインストール.command`または`LaserEditor をインストール.bat`を実行します。

## Macで開発元を確認できないと表示される

インストーラーファイルをControlキーを押しながらクリックし、**開く**を選びます。次の確認画面でも
**開く**を選びます。ターミナルへのコマンド入力は不要です。

## LaserEditorの画面が開かない

1. Docker Desktopが**Engine running**か確認する
2. `http://localhost:8000`をブラウザで開く
3. それでも開かなければ、同じインストーラーをもう一度実行する

設定画面は `http://localhost:8000/LaserEditor-settings` です。
**参加者アクセスURL・QR**と**参加受付**はここで確認します。

## ScanSnapの画像が入らない

1. 設定画面の**ラボ構成・AI**を開く
2. **外部画像取り込み**の監視がONか確認する
3. **監視フォルダを作成**が出ていれば押す
4. ScanSnap Homeの保存先が `Downloads/LaserEditor/Scan-Inbox` か確認する

取り込みに成功すると、元ファイルは受信フォルダから片付きます。同じ画像を再び投入しても、
新しい投入として処理できます。

## アンインストール後もフォルダが残る

正常です。通常アンインストールは参加者のデータを残します。
[運用ガイド](operations.md#アンインストールする)を確認してください。

## 解決しないとき

MacかWindowsか、画面に出た見出しと文字、止まった手順をそのまま連絡してください。
設定を繰り返し変更する前の画面が、原因の切り分けに役立ちます。
