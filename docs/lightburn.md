# LightBurn 連携

LaserEditor で集めたデザインを、LightBurn へ自動で送るための仕組みです。

---

## まず前提

**LaserEditor は LightBurn を入れません。** LightBurn は別の会社の製品で、
ライセンスもインストールもご自身でご用意いただくものです。
LaserEditor が LightBurn の設定を書き換えることもありません。

**LightBurn が無くても LaserEditor は使えます。** 管理画面から PNG をダウンロードして、
お使いの加工ソフトで開く運用ができます。これがいちばん確実な最低ラインです。

---

## 何ができるか

LightBurn が動いている PC に**中継エージェント**（小さな常駐プログラム）を入れると、
管理画面から加工キューに送ったデザインが、その PC の LightBurn に自動で開かれます。

```
管理画面で「加工キューへ送る」
        ↓
中継エージェントが受け取って .lbrn を用意
        ↓
LightBurn が自動で開く
        ↓
人が確認して Start を押す
```

**加工の開始（Start）は必ず人が押します。** エージェントは開くところまでしかやりません。

---

## 中継エージェントの入れかた

エージェントは **LaserEditor 本体とは別のインストーラ**です。
LaserEditor の管理画面から、その機械専用のものを作って配ります。

1. 管理画面 → **デザイン一覧タブ → 加工キュー欄 → [エージェント追加（インストーラ生成）]**
2. 機体名（例: `venue-mac`）・表示名・OS を入れて **[生成してDL]**
3. ダウンロードした zip を、**LightBurn が動いている PC** で展開
4. **Mac**: `install-mac.command` を実行 / **Windows**: `install.bat` を実行
5. 管理画面の一覧にその機体が緑で出れば完了

> **zip には管理トークンが入っています。導入する機体以外に渡さないでください。**

Windows では Python が必要です。入っていなければインストーラが案内を出します
（インストール時に「Add python.exe to PATH」にチェックを入れてください）。

### 外すとき

同じフォルダの `uninstall-mac.command` / `uninstall-win.bat` を実行します。
**ダウンロード済みの加工データは残ります**（不要なら手で削除してください）。

---

## LaserEditor 本体のインストーラとの違い

混ざりやすいので整理します。

| | 何を入れるか | どこに入れるか |
|---|---|---|
| **LaserEditor 本体**（`install.sh` / `install.bat`） | サーバー本体（Docker） | サーバーにする機械 1 台 |
| **中継エージェント**（管理画面から生成） | 小さな常駐プログラム | **LightBurn が動いている PC** |

同じ機械に両方を入れることもできます（会場で 1 台にまとめる構成）。
