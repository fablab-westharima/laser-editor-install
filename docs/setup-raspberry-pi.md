# LaserEditor を Raspberry Pi / Linux サーバーで動かす

会場に据え置く小さなサーバーで LaserEditor を動かす構成です。
Mac / Windows と違い、参加者用のサイトを常設しておけます。

> **公開前の最終確認が残っています。** 以前の版では Raspberry Pi 4B での動作を実機で確認していますが、
> **現在の版での最終確認は正式公開の前に実施します。**

---

## 必要なもの

- Raspberry Pi または x86_64 の Linux サーバー
- **64bit の OS**（Raspberry Pi OS は **Lite (64-bit)** を推奨。32bit 版では動きません）
- **USB SSD からの起動を推奨**（SD カードでも動きますが、書き込み寿命と速度で不利です）
- 空きディスク **10GB 以上を推奨**（最低 3GB。イメージ約 2GB + データ）
- メモリ **2GB 以上を推奨**
- インターネット接続
- [Tailscale](https://tailscale.com/) のアカウント（無料・公開 URL の発行に使います）

### メモリと機種について

正式な最低要件はまだ確定していません。分かっていることだけ書きます。

| 構成 | 分かっていること |
|---|---|
| Pi 4B / 1GB | 編集・共有・加工キュー中心の使い方なら動いた実績があります |
| AI 画像処理を使う | 1GB では実用になりません。2GB 以上を推奨します |
| Pi 5 / 8GB | 余裕があります |

**メモリが 2GB 未満の場合、インストーラが自動でワーカー数を 2 に落とします**（警告が出ます）。

---

## 1. インストール（SSH で 1 行）

Docker はインストーラが導入します（Mac / Windows と違い、Linux では Docker Engine の導入まで面倒を見ます）。

SSH でログインして:

```bash
curl -fsSL https://raw.githubusercontent.com/fablab-westharima/laser-editor-install/main/install.sh | sudo bash
```

- 事前に、アーキテクチャ・メモリ・空きディスク・SD カード起動などを確認して、足りなければ教えます
- 途中で失敗しても、**同じ 1 行をもう一度**実行すれば続きから修復されます
- 以後、**アップデートもこの同じ 1 行**です
- 完了画面に出る `http://<このマシンのIP>:8000` をブラウザで開けば使えます

中身を先に読みたい場合は、同じ URL をブラウザで開けばスクリプト全文が読めます。

### 何が どこに 入るか

| 場所 | 中身 |
|---|---|
| `/opt/laser-editor` | LaserEditor のすべて |
| `/opt/laser-editor/data` | 参加者のデザイン、スキャン、設定 |
| `/opt/laser-editor/.env` | 設定と管理トークン |
| `/etc/systemd/system/laser-editor-power.*` | 管理画面から安全に電源を切るための仕組み |

**Docker Engine は共有のソフトです。** LaserEditor をアンインストールしても Docker は残ります。

---

## 2. インターネット公開

1. `http://<このマシンのIP>:8000/admin-fablab-westharima` を開く
2. 管理トークンは `/opt/laser-editor/.env` の `LASER_ADMIN_TOKEN` にあります
3. **設定タブ → 「公開設定（インターネット公開）」→ [公開を開始]**
4. **🔗「Tailscale にログインする」リンク**をクリック → ログイン → 承認
5. **公開 URL と QR コード**が表示されます

---

## 3. スキャナ（ScanSnap）の扱い — ここが Mac / Windows と違います

**Raspberry Pi 構成では、スキャンの自動取込は動きません。**

ScanSnap Home は Mac / Windows で動くソフトで、保存先は**その PC の中**です。
Pi は別の機械なので、そのフォルダを直接見ることができません。

### v1 での正式なやり方: 管理画面へドラッグ＆ドロップ

1. いつもどおり ScanSnap でスキャンする（保存先は PC のフォルダのままで構いません）
2. **その PC のブラウザ**で Pi の管理画面を開く
3. **取込タブ**の枠へ、スキャンした画像を**ドラッグ＆ドロップ**する

自動取込と同じ処理を通るので、**同じ絵を二重に取り込むことはありません**（内容で判定しています）。

> **自動化は次の版（v1.1）で対応予定です。** スキャナのある PC に小さな常駐プログラムを置いて、
> Pi へ自動で送る仕組みを用意します。v1 には含まれていません。

**スキャナと LaserEditor を同じ機械に置きたい場合は、Mac / Windows 構成を選んでください。**

## 4. 日々の使い方

| したいこと | 操作 |
|---|---|
| サーバーを起動 | 電源を入れるだけ（自動で復帰します） |
| サーバーを停止 | 管理画面 → 設定タブ → **サーバー操作** → シャットダウン（SSH 不要） |
| 公開だけ止める | 管理画面 → サーバー操作 → **[公開を停止]** |
| アップデート | 1 の同じ 1 行をもう一度 → [運用ガイド](operations.md#更新する) |
| バックアップ | [運用ガイド](operations.md#バックアップ) |
| アンインストール | **`uninstall.sh`** → [運用ガイド](operations.md#アンインストール) |
