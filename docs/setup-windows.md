# LaserEditor を Windows で動かす

ワークショップに持っていく Windows PC 1 台で、参加者向けのデザインサイトを立ち上げて公開するまでの手順です。

> **公開前の最終確認が残っています。** 手順そのものは製品として用意されたものですが、
> Windows 実機での最終動作確認は正式公開の前に実施します。うまくいかない箇所があれば、
> 直さずにそのままご連絡ください。

---

## 0. はじめる前の確認（1 分・何も変更しません）

**「インストールは終わったのに Docker が起動しない」の原因はほとんどこれです。**
先に確認してください。

1. **Ctrl + Shift + Esc** でタスクマネージャーを開く
2. **「パフォーマンス」タブ → 「CPU」**
3. 右下の **「仮想化」** を見る

| 表示 | 進め方 |
|---|---|
| **有効** | そのまま次へ |
| **無効** | **ここで止めてください。** インストールを始めないでください |

「無効」は PC 本体の BIOS / UEFI の設定です。**Docker を入れ直しても直りません。**
この場合の選択肢は次のとおりです。

1. 対応 PC（Windows 11 がプリインストールされていた PC、または Mac）を使う
2. セットアップ済みの機器を用意してもらう
3. 有償の導入支援を利用する
4. PC に詳しい方向け: メーカー名 +「仮想化 有効化」で検索して設定する（自己責任でお願いします）

### 動作要件

- **Windows 11 がプリインストールされていた PC** を対応要件とします
- 仮想化が有効であること（上記）
- インターネット接続

---

## 1. Docker Desktop を用意する（最初の 1 回だけ）

**ここは LaserEditor ではなく Docker の作業です。** LaserEditor のインストーラは Docker Desktop を
入れないので、先に済ませてください。

1. https://www.docker.com/products/docker-desktop/ から
   **公式のインストーラ（`Docker Desktop Installer.exe`）** をダウンロードして実行
2. **Docker Desktop を起動する**
3. **初回セットアップを最後まで進める**
4. タスクバー右下の**クジラのアイコン**が動きを止めて安定し、Docker Desktop の画面が
   **「Engine running」**になるまで待つ
   （アイコンが隠れている場合は **「^」** を押すと出てきます）
5. **設定 → General → 「Start Docker Desktop when you sign in」を ON** にする
   （PC を起動すればサーバーも自動で立ち上がるようになります）

> **途中で止まっても、強制終了や再インストールを繰り返さないでください。**
> 中途半端な状態が残ると「すでにインストール済み」と誤認され、復旧が難しくなります。
> 画面をそのままにしてご連絡ください。

> Docker Desktop のアカウント登録・サインインは**不要**です。

**この 5 つが終わる前に LaserEditor のインストーラを実行しても、何も変更せずに止まります。**

---

## 2. LaserEditor を入れる

1. このリポジトリの **`install.bat`** と **`install.ps1`** を同じフォルダにダウンロードする
   （リポジトリ右上の「Code → Download ZIP」でまとめて取得し、展開してください）
2. **`install.bat` をダブルクリック**

黒い画面が開いて、確認 → 取得 → 起動と進み、最後にブラウザが開きます。

- PowerShell の設定を手で変える必要はありません（`install.bat` が面倒を見ます）
- 途中で失敗しても、**もう一度ダブルクリック**すれば続きから修復されます
- 以後、**アップデートも同じダブルクリック**です

### 何が どこに 入るか

| 場所 | 中身 |
|---|---|
| `C:\Users\<あなた>\laser-editor` | LaserEditor のすべて（設定・データ・管理トークン） |
| `…\laser-editor\data` | 参加者のデザイン、スキャン、設定 |
| `…\laser-editor\管理トークン.txt` | 管理画面にログインするための鍵 |

Docker Desktop 自体はこのフォルダの外にあり、LaserEditor は触りません。

---

## 3. インターネット公開（ブラウザだけ・約 3 分）

1. `http://localhost:8000/admin-fablab-westharima` を開く → **[トークンファイルを選択]** を押して、
   **`C:\Users\<あなた>\laser-editor\管理トークン.txt`** を選ぶ
2. **設定タブ → 「公開設定（インターネット公開）」→ [公開を開始]**
3. **🔗「Tailscale にログインする」リンク**をクリック → Tailscale にログイン → 承認
4. **公開 URL と QR コード**が表示されます（証明書の発行で 1〜2 分待つことがあります）
5. スマホ（Wi-Fi を切って 4G/5G）で QR を読んで、サイトが開けば完成

## 4. スキャナ（ScanSnap）から自動で取り込む

> **この節は Windows 実機での確認が公開前に残っています。** 手順は用意されていますが、
> うまく動かない場合は設定を触り続けずにご連絡ください。

ScanSnap Home と LaserEditor が**同じ PC**にある場合に使えます。

1. **ScanSnap Home** の保存先フォルダを決める
2. `C:\Users\<あなた>\laser-editor\.env` をメモ帳で開き、次の 1 行を追加する

   ```
   LASER_EXTERNAL_INBOX_HOST=C:/Users/あなた/Documents/ScanSnap Home folder
   ```

   - **区切りは `/`（スラッシュ）で書いてください。** `\`（バックスラッシュ）で書くと、
     フォルダが見つからないまま何も起きません
     （`install.bat` を再実行すると自動で直しますが、最初から `/` で書くのが確実です）
   - 空白を含んでいてもそのままで構いません（引用符は不要）
3. `install.bat` をもう一度ダブルクリック

**LaserEditor はフォルダの中身を消しません。** 取り込んだ原本はそのまま残り、枚数が増えると
`_archive` サブフォルダへ移動します（削除ではなく移動です）。

## 5. 日々の使い方

| したいこと | 操作 |
|---|---|
| サーバーを起動 | **PC を起動するだけ**（Docker Desktop が自動で立ち上がります） |
| サーバーを停止 | **クジラアイコンを右クリック → Quit Docker Desktop** |
| 公開だけ止める | 管理画面 → サーバー操作 → **[公開を停止]** |
| アップデート | `install.bat` をもう一度 → [運用ガイド](operations.md#更新する) |
| バックアップ | `laser-editor` フォルダを丸ごとコピー → [運用ガイド](operations.md#バックアップ) |
| アンインストール | **`uninstall.bat`** → [運用ガイド](operations.md#アンインストール) |

---

## 6. 困ったとき

[困ったとき](troubleshooting.md) を見てください。Windows で特に多いのは次の 2 つです。

- **「インストールは終わったのに Docker が起動しない」** → 0 章の仮想化設定。入れ直しでは直りません
- **クジラアイコンが見つからない** → タスクバー右下の **「^」** を押すと隠れているアイコンが出ます
